# CUDA kernel 设计

| Kernel | 工作分配与存储 | 为什么这样写 |
|---|---|---|
| `angles` | 每角一个线程，`sincosf` 写一对 `float2` | 角度表整次重建只算一次。`back` 通过 `const __restrict__` 指针读取，不在每个体素重复算三角函数。 |
| `ramp` | 每个频点一个线程，用 FP64 累加有限离散 Ram-Lak 响应 | 直接采样连续的 `abs(f)` 不等于离散冲激响应，特别是小探测器的 DC 分量。 |
| `pre` | 连续写入复数行；锥束预加权，行宽补到 ≥ 2u 的二次幂 | 同一 plan 覆盖最后一个不满的角度批次；缺失行和超出探测器的列写零。 |
| `spectrum` | 批量 C2C 正变换后，每个线程将一个复数频点乘以滤波器 | 所有行复用同一频率响应。R2C 会改变调用路径，需要另外比对输出。 |
| `unpack` | 从逆变换取实部、去掉水平补零、乘角度及几何归一化系数 | 只输出有效探测器范围；与后面的插值表分开，保留运算顺序。 |
| `pairs` | 一个线程写一个 `(左值, 右值−左值)`，覆盖已用完的 FFT 工作区 | 为多个体素复用水平差分；虚拟左列和两个零哨兵保留边界的部分插值贡献。 |
| `back` | 16×8 线程块；一个线程固定 `(x,y)`，寄存器中累加最多 16 个 z 体素 | 同列共享透视分母、`u` 和权重；每四层重算 z 基点，保持非二进制体素间距的 FP32 舍入顺序。硬件纹理插值并非这里的软件 FMA 序列。 |

[REVIEW] 只保留线程尾界不能实现相同的零延拓、补零、末层屏蔽和插值；这些算法分支保留。角度表是全局内存，没有声称使用显式 `__ldg` 或 `__constant__`。若换成其他存储方式，应先取得同输入的对照结果。

主 API 只接收投影、几何、输出体积；输入一致性在入口检查一次。[REVIEW] Release 编译掉 launch 状态探针，仍检查分配、cuFFT、主机/设备拷贝与最终同步拷贝的返回状态，避免把失败当作有效输出。
