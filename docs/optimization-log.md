# 四项优化决策

这些是不同粒度的实验，不是四个可以连乘的加速比。

| 决策 | 证据 | 结论 |
|---|---|---|
| 以行批处理取代逐行提交，在角度循环外创建 cuFFT plan | 当前 720 角 trace 中，45 批总计 90 个 cuFFT kernel；整个滤波阶段 61.02 ms | 保留 plan 复用。未单独计时“每行创建 plan”，不报加速比。 |
| 预编码水平差分，用完的 FFT 缓冲作插值表 | 同一 trace 中 `pairs` 总计 2.10 ms，反投影总计 379.19 ms | 额外的滤波 pass 有实际代价；不把整个版本的改进归因于单个算子。 |
| 比较每线程 8 和 16 个 z 层 | GB10 的独立分块实验中，固定 16×8 线程块。整卷六对测试，反投影中位数 **360.08 → 285.76 ms**（16 → 8）；另一薄层的反投影也更快，但进程时间未过既定门槛 | 不能写成“8 → 16 一定更快”。本次保留原 16 层主线与四层舍入分组，不把另一个实现的时间当成本次性能。 |
| 三个输出复用同一批滤波结果 | [历史六组 A/B](../experimental/reports/gb10/multigrid-timing.json)：滤波批次 135 → 45；反投影均为 135 次；进程中位数 1742.95 → 642.52 ms | 整个三网格请求 **2.71×**。顶层 API 是单网格，不提供该多输出接口。 |
