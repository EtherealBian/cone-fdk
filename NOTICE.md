# Data and software attribution

The corrected 90-view walnut fixture in `examples/walnut/` and the axial sweep in `examples/walnut-sweep.gif` are derived from Alexander Meaney, University of Helsinki, [Cone-Beam Computed Tomography Dataset of a Walnut](https://doi.org/10.5281/zenodo.6986012), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Processing includes angular subsampling for the fixture, center correction, spatial binning, per-view air normalization, negative logarithm and (for the animation) FDK reconstruction. The 90-view subset uses TIFFs 0001, 0009, …, 0713. Original data are dark/flat corrected. No endorsement is implied.

Algorithm: L. A. Feldkamp, L. C. Davis and J. W. Kress, *Practical cone-beam algorithm*, JOSA A 1, 612–619 (1984), DOI 10.1364/JOSAA.1.000612. The implementation uses NVIDIA's CUDA Runtime and cuFFT; neither is redistributed. [ASTRA Toolbox](https://astra-toolbox.com/) is an independent reference; the native executable does not link to ASTRA. See `LICENSE` for this repository's code license.
