# 一个统一比例能否修好逐孔体积？

固定同一批孔，在曲率检测的边界和原图灰度给出的边界之间选择一个**所有孔共用**的位移比例。用原来的 24 张校准切片求得 **9/11**，不是对迁移区挑出的最优值。没有增加或失去匹配，也没有因连通性而回退。2 号靠近 15% 门槛，但另外两件的误差增加。

|开发件|校准中能给出方向的完整孔|迁移区匹配 / 合格预测 / 合格参考|体积误差 P95：曲率 → 使用 9/11|调整后 Dice|研究区通过项|
|---|---:|---:|---:|---:|---:|
|2|13|46 / 47 / 49|22.55% → 15.95%|0.95103|10/11|
|3|1|23 / 23 / 24|18.36% → 31.88%|0.97362|9/11|
|5|0|11 / 12 / 12|19.64% → 28.95%|0.98077|8/11|

这里的 P95 是全部匹配孔的绝对相对体积误差，也就是本实验的同孔 P95。本实验只用完整三维校准孔拟合比例。5 号没有这样的配对，独立于误差表现，这也不满足事前筛选条件。3 号的体积中位数在原生评分中为 5.000000000000004%，按冻结的未舍入判定未通过；没有调整判定规则。

## 知道参考体积后，能排除哪些策略？

固定两个端点都能匹配的 46 / 23 / 11 个孔，只审计请求的整数体积。在 [0,1] 内有 1,513 个不同断点（含两端）；逐个检查断点与每个开区间，共 3,025 种代表位置。**没有一个共同比例让三件同时 ≤15%**。最小化三件中最差 P95 的精确值为 12353/618 = **19.99%**，一个见证是 5/58。只针对某一件事后选统一比例也未必够用：

|试件|该件独选一个比例的最低 P95|每孔知道答案，只选两个端点之一|每孔知道答案，可在端点间任选整数|
|---|---:|---:|---:|
|2|14.29%|11.39%|5.61%|
|3|15.92%|12.67%|12.67%|
|5|19.47%|12.84%|12.84%|

两个端点提供了互补信息。上表后两列都使用了参考答案，不是可以部署的预测，也不能证明其余指标通过。统一比例的结论只对请求体积成立，不排除按几何约束逐孔回退、作不同决定或用其他边界模型。此处是先前研究过的开发迁移区，不是跨深度验证，更不是物理尺寸认证。
