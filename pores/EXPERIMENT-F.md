# Candidate F — spatial residual field (development preregistration)

This is a separate candidate, not a retuned split pilot. Test on the original formal ROI in development specimens 2/3/5, reporting all eleven unchanged gates, including errors on complete objects as small as 64 voxels. No labels from either pilot, formal scoring ROI, other specimen, or reserve 4/6 enter training. Fit one small plane convolutional network per scan using just that scan's original 24 calibration layers. Do not sweep models, thresholds or seeds on formal results. Cross-scan performance is not established by a development pass.

* Input: real source context; 3×3×3 median and six existing CUDA adaptive NLM estimates. For each estimate use mapped intensity, signed difference from the local radius-5 Bernsen midpoint, and contrast surplus relative to that scan's published setting. Add the mapped median, neighboring-slice mean and absolute difference of the second estimate's signed margin, and its clipped Bernsen decision score. No coordinates, specimen ID channel, target components, or annotation at inference. Clip scaled inputs to [-8,8].
* Train a four-stage plane CNN (16 channels, 3×3, dilations 1/2/4/1, ReLU) and a pointwise logit correction to the bounded Bernsen score. Single network, no topology edits and no ensemble at inference. Seed 61429, AdamW, 1200 updates at 0.002 with cosine decay to 0.0001, weight decay 0.0001. Each batch has eight 32×32 calibration tiles with losses on the central 16×16 only; random joint axis flips/transposition. Cycle three center distributions: uniform ROI, one voxel from a reference transition on either side, and those transitions nearest a 16..255-voxel complete reference object (fall back to all boundaries if none). Score binary cross entropy plus 0.1 times the mean per-tile absolute predicted-minus-reference foreground count divided by (reference count+16). Fixed inference threshold: logit >=0. Calibration sampling is explicitly label-assisted; inference is not.
* Compute and publish all three formal development prediction digests before reading their labels for F scoring; earlier candidates have seen these regions, so this is not a blind validation. Keep every native component, verify slab CSV identity and SciPy agreement, retain both masks, per-ID tables, all errors, source provenance. Independently replay goals before any freeze. Only all eleven passes per specimen can unlock a separate freeze workflow. Any implementation or runtime equivalence discrepancy must be disclosed and corrected before acceptance.
