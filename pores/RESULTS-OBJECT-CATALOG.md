# 现有方法是否曾经把足够多的孔量准？

**有，但没有一种现成方法能同时做到。** 这次先不训练新模型。对同一迁移区的十二项实验、每件 33 组已发表结果按完整掩膜去重，再逐个参考孔查询：若事后知道正确的参考 ID 和体积，从各方法原本已经一对一匹配的完整预测中择优，能否同时达到 ≥90% 参考孔覆盖率和 ≤15% 体积误差 P95？三件的理想选择都能做到；没有一个原封不动的输入掩膜同时通过这两项。**理想选择用到了答案，不能算算法，也没有检查另外九项。**

5 号几乎没有余量：在这个目录里，再丢一个已匹配孔就达不到覆盖线。参考孔 44 有 65 个体素，即使挑误差最小的完整匹配，仍相差 16.92%。这不使整件的第 95 百分位自动失败。2、3 号则各有一些覆盖余量。没有因为孔小而删除它们，也不能用 2 号的余量补 5 号。

账本包括未匹配 ID、每个被匹配孔的全部候选体积、每一张掩膜在其各自预测总体上的分母和误差。重算先核相同的参考掩膜摘要、ID 和三维体积，然后从逐孔 CSV 独立计算相对体积误差。研究中复用的对照只算一次，指向相同掩膜的原始 CSV。P95 用精确有理数线性插值；不把 89% 舍入为 90%。理想值允许挑孔和方法，并忽略冲突与未匹配的预测，因此不能解决预测侧覆盖，更不能当作正式精度。它提示下一步要检验的是**没有参考答案时，如何保住完整孔并识别可信的体积**，而不是继续微调翻转方向。
