# 让检测器先在没训练过的试件上犯错，能教会它选边界吗？

**校准确实变难了，迁移测量没有变准。** 本轮保留原先的两个三维边界（曲率、灰度面定位），只替换用来教截面选择器的样本。之前用检测器见过的校准区；这次把 2、3、5 号依次排除，只用其余两件从头训练检测器。三个留出的校准区都产生了更多体素错误。用这些截面重拟合同一个选择器，原先的 80 个匹配孔全部保住，但没有一个试件达到预定的同孔 P95 至少降低 2 个百分点。3 号反而多了一个体积误差超过 15% 的孔。

## 一次只改一件事

每折在两件的 z=[160,184) 上取 786,432 个带标签的体素训练 96 棵树；留出件不参与该折拟合。对留出件的 24 层完整原图预测后，才把其校准参考与预测截面配对。截面汇总成同一套三试件共享的系数，因此这不是对最终选择器的独立新试件验证。迁移仍用原来的曲率模型和两个封存的边界；没有换检测器、阈值、规则或计量口径。

|留出件（训练件）|旧校准 FP / FN|留出校准 FP / FN|改变的体素|可用截面 / 三维结构（其中触边）|
|---|---:|---:|---:|---:|
|2（3、5）|794 / 824|1,587 / 828|1,437|235 / 34（20）|
|3（2、5）|6,852 / 7,483|6,662 / 10,653|8,310|904 / 40（36）|
|5（2、3）|3,650 / 3,201|3,902 / 3,869|2,708|304 / 14（13）|

FP 是多标成孔的体素，FN 是漏标的孔体素；每件都是 24 × 256 × 256 个体素。同一结构内的多个截面没有当作多个独立孔。

## 另一段 96 层：保住了哪些孔，又有没有量准？

|开发件|匹配 / 合格预测 / 合格参考（三组相同）|体积误差 P95：曲率 → 旧选择器 → 留出校准选择器|选择新边界 / 合格预测：旧 → 留出校准|选对较准端点 / 非平局：旧 → 留出校准|研究通过项（新方法）|
|---|---:|---:|---:|---:|---:|
|2|46 / 47 / 49|22.55% → 22.55% → 22.55%|15 → 18 / 47|26 → 25 / 44|10/11|
|3|23 / 23 / 24|18.36% → 18.36% → **20.51%**|5 → 9 / 23|13 → 9 / 23|8/11|
|5|11 / 12 / 12|19.64% → 19.64% → 19.64%|1 → 4 / 12|7 → 8 / 11|10/11|

逐个配对比较旧、新选择器，2/3/5 号分别有 3/4/3 个匹配孔从曲率边界改选灰度边界；没有反向改选，没有新增或丢失匹配。这 10 次改选没有使任何原本超线的孔进线，却把 3 号一个原本合格的孔推到线外。5 号体积误差中位数从 3.88% 降到 2.70%，P95 仍为 19.64%；选得更准的孔数上升，不代表改善的是误差较大的孔。一个有用的负结论是：**只让这套二维面积回归看到留出误差，不足以解决逐孔体积问题。** 这不能证明原始扫描已无可用信息。
