# Slice-area supervision: paired development screen

H learned whole-volume mass from only one eligible calibration object in specimen 5. A pore cut by either end of a 24-layer calibration stack cannot supervise its total volume, but its interior XY sections have observed areas. Test that distinction without expanding the labeled region. Never count neighboring sections as independent pores or infer missing volume. Development 2,3,5 only; do not access 4 or 6. This screen is not a formal candidate or a confirmation.

Use F's fixed 22 inputs, architecture, Bernsen prior, CPU deterministic training seed 61429, AdamW 0.002→0.0001 over 1800 updates and H's balanced six-patch batches/BCE + 0.1 relative tile-count penalty. Train two shared models from the same initialization with identical base patches and augmentation; no complete-object term in either. In the **area** arm only, every fourth step add 0.5 × |sum(sigmoid(logit)) − true area| / true area over one full owned section. Auxiliary sampling uses a separate RNG (seed 61430). No threshold sweep. Native CUDA deployment; same hard threshold zero in both arms.

Use the registered x=[360,616), y=[376,632), z=[160,184) calibration stacks. Label 3-D parents by six-connectivity, each 2-D section by four-connectivity. Retain individual planar components of 4..255 pixels with two pixels of XY margin; allow 3-D parents that touch the z or lateral faces, but never call them complete volumes. Own the component and background within Euclidean distance 2 whose nearest foreground belongs to this planar component (SciPy EDT tie convention). Cycle specimen 2,3,5; within each draw uniformly by eligible parent, then uniformly among its eligible sections. Publish counts of actual distinct parents, parent clipping status, sections, and distinct draws. Abort the experiment if any scan has no eligible parents. These labels never enter inference.

Predict both arms on the same already-studied development transfer slabs at z=[256,352), x/y unchanged. Seal both weight hashes and all six raw-inferred masks publicly **before scoring either arm there**. This is not independent confirmation. Compare to the matched-training control, not H in another ROI. Repeat native-component checks, both slab sizes, CPU/CUDA decision comparisons, per-reference pairings and all eleven numerical tests as descriptive outcomes. Research screen: require on **each** specimen at least five common eligible reference IDs; on those same IDs require volume-error P95 lower by ≥2.0 percentage points; neither side's coverage may decrease and voxel Dice must not decrease by more than 0.002. Otherwise do not promote, including a small denominator. Publish both outcomes regardless. All predictions use one unchanged model per arm for all three scans. Only a later separate formal evaluation can address FINAL-GATE.
