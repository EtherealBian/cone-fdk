# Can a one-gray-level preprocessing difference explain the remaining development errors?

Historical Fiji agreed on identical bytes; the cited historical denoiser did not improve the calibration check. Before trying another learned operator, measure how much the **input to the strict Bernsen decision** would have to differ. This is an optimistic sensitivity bound for the specific fixed square h=30 CUDA estimator, not a new segmentation, measurement candidate, or model fitted to reference labels.

Use original formal development 2/3/5 ROI x=[360,616), y=[376,632), z=[400,528), native 3×3×3 median, 21×21/5×5 CUDA square NLM, published linear mapping rounded and saturated to uint8, strict radius-5 ImageJ disk dx²+dy²≤26, published contrast for each scan. Give each input byte in the footprint any integer value within ±e of its original value clipped to [0,255]. Define each output voxel's flip radius as the **minimum** e=1..8 for which some input patch changes its strict decision; store 9 for no flip at e≤8. Store signed int8, positive=pore, negative=solid. Use real 18-pixel context. Independently compare every radius-zero mask to production and replay selected patch radii by enumerating center and both neighbor extrema. Require a separate brute-force test that changes the individual neighbors, not just the implementation's three numbers. Reject an implementation mismatch rather than scoring it.

Seal all three predicted signed maps, raw archive digests, baseline masks and numerical diagnostics publicly **before** reading formal development masks for this comparison. Prior candidates saw these specimens. For e=0,1,2,4,8 report unchangeable false positives/negatives and an optimistic upper bound on Dice, precision and recall against the NIST digital reference; for each eligible complete >=64-voxel reference pore, report the portion of its voxels that cannot be classified as pore. Different voxels may need mutually inconsistent changes to the same input byte, so the resulting oracle is an upper bound, not an attainable segmentation or volume estimate. No threshold/denoiser choice, no reserve inputs, no change to FINAL-GATE. If e=1 cannot reach a voxel gate even optimistically, a uniformly one-byte change cannot fix that gate for this baseline; if all are reachable, this does not validate rounding as a cause. Do not infer physical uncertainty from this experiment.
