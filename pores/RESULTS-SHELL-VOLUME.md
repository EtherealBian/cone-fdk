# 保住找孔结果后，只改一层边界够不够？

在同一开发迁移区，锁住三维曲率模型找到的孔。让另外四种方法对能一一对应的完整孔估体积：至少两份合格估计才与检测器一起取中位数，再在检测边缘的一层体素内移动到该体积。与直接换整孔不同，遇到相邻孔、可能断裂或缺少估计，可以相应排除体素或保持原孔不变。三个试件都保住了原匹配，但三件都没有通过预先登记的改善筛选。

|试件|匹配 / 合格预测 / 合格参考（前后相同）|体积误差 P95：不改 → 实际改后|所请求的中位体积 P95¹|估计范围内最理想的 P95¹|实际改动孔数 / 体素数|研究通过项（改后）|
|---|---|---|---:|---:|---:|---:|
|2|46/47/49|22.55% → 21.63%|25.17%|19.18%|31 / 447|10/11|
|3|23/23/24|18.36% → 18.61%|18.61%|15.30%|16 / 103|9/11|
|5|11/12/12|19.64% → 19.19%|19.19%|16.00%|5 / 18|10/11|

¹ 固定原检测器的同一批匹配参考孔，每个孔权重相同，弃判也计入。2 号有一份请求会把原孔断开，实际退回原体积，因此请求与应用的 P95 不同。最后一列百分位下界**不是算法成绩**：允许知道答案，在被接受的完整体积估计之间选择任意整数，且忽略几何限制；不足两位供体时只能用检测器本身。在这组输入和对应规则下，即使如此仍达不到 15%。这不排除新估计器，也不证明必须增加边界层数。

所有估计共同偏小、连选最佳值仍相差超过 15% 的参考孔：2 号 #22、#56、#63、#87；3 号 #71、#137；5 号 #26。例如 5 号 #26 的参考体积为 309，合格估计只有 225–244；2 号 #87 的检测体积为 64，参考为 91，没有足够供体。这里需要的是范围外的体积信息，仅改变中位数的权重无法解决这些例子。
