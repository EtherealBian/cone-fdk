# Cross-method disagreement review (diagnostic only)

Before analyzing E results: for **each** eligible E detection (interior, ≥64 voxels), find the best-IoU eligible peer in the C segmentation and the D segmentation of the same raw crop, independently. A peer agrees only at IoU ≥0.5 and if the absolute count difference is ≤15% of the E detection size. Both peers must agree to leave the object unflagged. No threshold fitted from outcomes. Compute flags using predicted component masks only; do not use reference masks to form the queue. Classify a flagged or unflagged E prediction as problematic for this descriptive check if it is unmatched in the original E-vs-NIST evaluation or its matched volume error exceeds 15%. Count every eligible E prediction; report also that an E-missed reference cannot be flagged by this queue. Agreement may be wrong and never serves as a release gate, uncertainty interval, or reason to delete a detection.
