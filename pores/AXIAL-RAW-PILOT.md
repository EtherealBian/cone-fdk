# Can neighboring raw CT planes recover pores missing from a plane-based estimator?

The byte-radius study suggests that changing only the rounding of one denoised XY plane cannot restore all development objects. This is a new paired raw-to-mask experiment, not a physical tolerance or a final freeze. No reserve data. Use the original calibration z=[160,184), x=[360,616), y=[376,632), in 2/3/5; decode labels only in this region during training. Infer on the already studied development transfer interval [256,352), with real raw halos. No transfer or formal labels in model selection. One network per arm shared across the three scans; never pick different arms for different scans.

Both arms have the same ten input channels, fixed square CUDA h=30 (mapped intensity units), strict digital Bernsen prior, per-scan published mapping and contrast, and identical parameter count. Give both the mapped center raw and 3-D median, continuous denoised intensity, disk contrast and high-contrast margin and strict-branch signed prior. In **axial** only, supply (neighbor mean minus center, absolute neighbor difference) on the original unfiltered source at z±1 and z±3, invariant to z reversal. In **plane** the four difference channels are zero: this disables the additional raw context, not the existing 3-D median. No synthesized slices and no coordinate/specimen ID features. Intensities normalized with fixed scales. Final labels predicted by a residual logit added to the same clipped prior (fixed threshold zero). No morphology.

Use 4 valid 3×3 convolutions (dilation 1,2,4,1, width 16, ReLU) and a zero-initialized linear 1×1 head. CPU deterministic AdamW, seed 61429, 1,800 updates, 0.002→0.0001 cosine schedule; H's same six balanced 16×16 output patches and dihedral augmentation per step, BCE + 0.1 soft absolute relative tile-count penalty. Both arms see identical coordinates, labels, initialization, and base channels. No validation checkpoint choice. Export weights and infer through the native CUDA valid-convolution kernel; compare every transfer decision to CPU and report discrepancies. Treat a decision mismatch as a failed replay; do not select by the better backend.

Seal both weights and six masks publicly before decoding transfer truth for this comparison. Use the same six-connected, complete >=64 voxel, one-to-one IoU >=0.5 measurement and 8/37-slab checks as the section-area experiment. Report both-sided coverage, all 11 gates, and all per-reference pairings. Advance only if on *every* specimen at least five common pores, their P95 absolute relative volume error improves by >=2.0 percentage points, neither side's coverage decreases and Dice decreases by no more than 0.002. Advancement would authorize formal development evaluation only. Report all outcomes and do not open 4/6.
