# Small-seed recovery on native intensity (development only)

In formal H, all four high-local-contrast missed references on specimen 3 overlap most with predictions below 64 voxels. That observation does not tell us whether enlarging small supports recovers pores or invents them. Test a local, bounded intervention on the already sealed census masks in the *different*, previously studied transfer slab [256,352) of 2/3/5. Prior transfer scores are public, so this is a development experiment, not blind validation. No refitting, no changing the minimum size, no threshold choice per scan. Never open 4/6.

1. Use every non-face-contact six-connected census seed of 8..63 voxels. Freeze the rest of the mask. For each seed take the median native uint16 in its support and in its full [2,4] Euclidean shell (real four-voxel raw halo). If inside is not darker, abstain. For native background within Euclidean center distance <=2 from this seed allow a voxel only if internal to all six ROI faces and no other original foreground within Euclidean distance <=3. This ownership guard prevents distinct expanded seeds from becoming adjacent. Cubic padding must not manufacture raw signal.
2. Native-intensity arm: accept allowed voxels where the median of the central original raw value and its six axial neighbors is <= the midpoint of the two seed-specific medians. Keep only sites reachable from the seed in six-connectivity through accepted sites. Preserve every original foreground voxel. No minimum grant to make a component pass 64. CUDA computes the native seven-sample median on the transfer volume; reproduce every output with a separate CPU rank calculation. All intensity comparisons can be exact using doubled medians. Report native and reference CPU decisions and source hashes.
3. Matched-count geometry control: add exactly the same number of allowed voxels to each seed, by a six-connected frontier priority queue, closest Euclidean distance squared to the original seed first, then x-fastest flat index. This control uses the gray arm's count but not the gray ranking; neither arm sees transfer labels. Record every seed, raw medians, allowed/added counts, original/final sizes, newly eligible IDs, invariants (no merge, face change, deletion or edits away from eligible seeds). Both methods leave every previously eligible prediction unchanged. Publish both masks per specimen and full proposal records *before* reading transfer annotations for this experiment. Compare both with frozen census, same native object tables (slab depths 8 and 37) and independent per-ID checks.
4. Count newly eligible predictions that match previously unmatched eligible references and those that do not. Keep unmatched entrants in the prediction denominator. Prespecified **mechanism screen**, not a release: raw arm must rescue >=1 missed reference on >=2 specimens, never gain an unmatched eligible prediction on any specimen, lose no baseline match, and not increase same-ID P95 on any specimen. It must improve at least one reference IoU over the geometry control for a newly matched raw-arm reference (absent counts as zero). Report counts, newly gained/lost IDs, full 11 gates, both coverage fractions and all-matched P95 even if this fails. A size-limited change cannot repair unrelated metric errors. Only FINAL-GATE permits reserve use. Do not reuse the formal H IDs as seeds or labels here.
