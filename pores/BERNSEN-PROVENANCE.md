# Bernsen decision provenance: implementation versus printed equations

Kim et al., DOI 10.1016/j.addma.2017.06.011, section 4, describe an ImageJ implementation, yet the printed equations test center intensity in low contrast and assign equality to pore at a high-contrast midpoint. The Fiji plugin source available by 2016-12-31 (fiji/Auto_Local_Threshold commit f5ad12b1edebf79c5ef656c0c7eeb83eb282952a) instead uses integer midpoint and distinct comparisons. Neither is asserted to be the exact software version or configuration used by NIST. They can disagree even with identical filtered pixels. Isolate this uncertainty before changing the source denoiser.

Use signed or widened uint8 arithmetic throughout, the same radius-5 ImageJ footprint, unchanged published contrasts and fixed square 21×21/5×5 NLM h=30 (mapped units). Quantize after denoising as before. Run all three on the same already-studied calibration check x=[512,616), y=[376,632), z=[176,184) of development 2,3,5 with 18 raw-context pixels. (1) Production strict digital implementation. (2) Compile the unmodified 2016 Fiji plugin with ImageJ 1.51h, run its Bernsen operator on the same unsliced-halo byte planes (pore=black), crop only after thresholding. Require zero interior decision disagreements on all specimens to validate this independent implementation comparison. (3) Paper-literal low contrast: center≤128; high contrast: 2×center≤hi+lo. Require a Dice gain ≥0.005 on every specimen, precision and recall each no worse by >0.005, to advance the printed rule. No choosing a different rule per specimen.

Record full input byte hashes, binary mask hashes, counts split by low/high contrast, false positives and false negatives added/removed, actual tool versions and dependency hashes. Publish all predictions before opening any check labels for this screen. Also report errors unchanged under both candidate decisions, not an accuracy bound for other preprocessing. The unchanged reference in this experiment is digital; this is not a formal measurement. External plugin and upstream jars are not redistributed. Source URLs and build recipe must be pinned.
