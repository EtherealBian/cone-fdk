# Historical non-local means: independent upstream filter screen

Our same-byte Fiji comparison reproduced the final threshold but not the upstream gray image. Kim et al. cite Buades, Coll & Morel, DOI 10.5201/ipol.2011.bcm_nlm. Test the authors' **actual reference library** as an alternative to the current CUDA filter; do not infer that Avizo embeds this code. Unlike the pointwise fixed-bandwidth surrogate the reference estimates overlapping full patches, corrects squared distances for noise, gives self the maximum other-patch weight, and uses a tabulated exponential. This compares the full algorithm, not one of these changes in isolation. This CPU path is an independent research instrument; it does not replace the deployed CUDA implementation.

Compile the original IPOL source snapshot from <https://www.ipol.im/pub/art/2011/bcm_nlm/revisions/2020-11-05/nlmeansC.tar.gz>, SHA-256 `649ad40b8676e29309c478e351bb95ab7f1b2733a4994b94094b29f4758b6902`. Link an adapter directly to `nlmeans_ipol` (not its re-noising demo); single thread, no fast math. Use native-unit 3×3×3 median input; square search radius 10, patch radius 2, fFiltPar = 0.6 as a hypothesis, never an assertion of parameter equivalence. In mapped gray units fit sigma in the fixed set {10,15,20,25,30,35,40}, dividing by the published mapping slope for the call on native input. Do not pre-clip or re-noise the data. Standard mapped byte conversion and strict Bernsen disk **after** filtering. Use 24 source XY context pixels so all in-plane calculations include real surrounding data. Check the input/output, complete finite values and data lengths. Independent scalar sample audit of the scatter/normalization on an interior synthetic neighborhood and constant-image invariance before scoring.

Specimens 2/3/5 only. Fit by maximum Dice on x=[360,464), y=[376,632), z=[160,164) (smallest sigma on ties). Compare on x=[512,616), y unchanged, z=[176,184), a previously used development check. Publicly seal chosen sigma, every fit score, and raw-inferred masks before this comparison reads check truth. Reproduce the previous fixed CUDA h=30 square control on all three; report even adverse metrics and overlap errors. Require Dice gain ≥0.005 on **each** specimen, precision and recall each no worse than 0.005 below the control. If the screen passes, first port/verify the operator on CUDA and test a separate, predeclared 3-D development ROI, not a formal freeze. If it fails, do not advance the choice by picking specimens or parameters. Do not consult 4/6.
