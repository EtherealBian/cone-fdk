# Candidate H — shared calibration with a complete-object mass loss

Registered on development specimens 2, 3, 5 before training H or scoring its formal fields. E, F and G already used the development evaluation regions. This is not a blind test. The candidate addresses the gap between a loss on a random tile fragment and relative error on an entire small pore. It changes training, not the definition of a pore or the measurement program. No post-hoc splitting, per-specimen choice of model, threshold tuning, or evaluation labels in fitting. All positives and negatives are reportable.

Use F's 22 channels, physical source context, native plane CNN architecture, signed Bernsen prior and threshold zero. Fit **one shared set of weights** using only the original 24 annotated layers (z=160..183, x=360..615, y=376..631) of each development scan. No external labels or spatial coordinates. For any future confirmation the development weights will be used unchanged, with the scan's already published mapping/contrast, without calibration labels or fine-tuning on 4 or 6. Do not open them now.

- Label 6-connected reference objects in each calibration stack. Retain objects of 16..511 voxels that have two source target voxels of margin in all dimensions (expand the bounding box by 2). In each expanded box own only foreground of that object and background up to Euclidean distance 2 whose nearest foreground belongs to that object. Publish counts in 16..63, 64..127, 128..255 and 256..511 bands. Train with the full object, not individual slices cropped to a reconstruction of its volume.
- CPU deterministic Torch; same network, seed 61429, AdamW and 0.002→0.0001 cosine schedule as F, now 1800 updates. Every update includes two F-style 16×16 labeled patches from each scan (uniform/boundary/small-boundary cycle, joint flips and xy transpose). Minimize mean voxel BCE plus 0.1 times F's per-tile relative count penalty. On every fourth update add **0.5 times absolute signed soft volume error divided by actual object size** over one entire owned region; count foreground probability with sigmoid and use actual reference count, not a smoothed denominator. Cycle uniformly through scans with eligible objects and pick one eligible object uniformly in that scan using the fixed RNG. Do not manufacture an object for empty strata or penalize unowned neighboring pores. No augmentation in this second branch. Publish training trace, source hashes and single weight digest.
- Register source before full prediction; publicly seal all three H fields before decoding the formal annotation for H. On the unchanged formal regions compute all eleven gates, every native CSV row, independent SciPy, 8/37 slab equality and source/viewer replay. Compare modes on same reference IDs and list missing or gained matches. Independent convolution replay plus the full FINAL-GATE sequence is required for any acceptance. Prediction seal is not a confirmation freeze.
