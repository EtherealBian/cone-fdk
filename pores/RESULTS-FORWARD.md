# 看得懂灰度，不等于量得准孔

**三件校准检查都通过，三件迁移分割都失败。** 给出孔的数字边界，学习到的三维核比“体素只取自身颜色”更能预测边界附近的原始灰度。反过来，从灰度同步修改孔的边界时，三个试件没有留下一个合格匹配。未晋级，未更改正式候选或 64 体素的计量下限。

### 事后诊断：这一步连自己的目标函数都没有改善

不打开参考标签，重新计算“灰度拟合残差平方和 + 边界惩罚 + 偏离原掩膜的惩罚”，除以 ROI 体素数。共享核同步更新前 → 后：2 号 **0.008831 → 0.061899**，3 号 **0.015476 → 0.127716**，5 号 **0.008897 → 0.080662**。三件分别有 **789,134 / 392,362 / 437,849** 个新增前景距旧前景超过 4 体素；这个距离不依赖参考标签，不能单独证明每个都是假孔。中心核的目标反而在三件都下降。共享核相邻位置的灰度支持重叠，逐位置有利的翻转一起做未必有利；这也没有证明换优化器就能改善计量。[逐项复算](evidence/forward/energy.json)。
