# 漏配的孔，在原始扫描中都缺乏对比度吗？

**不是。** 对正式候选 H 的三个开发区，分别取每个完整合格参考孔及预测孔（六连通，≥64 体素）。用原始 TIFF 计算孔内灰度中位数与外壳中位数之差，并按壳内波动归一化。下面的 CNR 是局部灰度指标，不是仪器信噪比。没有用它调整分割，也没有去掉任何一个漏配或误报。

|试件|参考：匹配 / 未匹配；两组 CNR 中位数；AUC|预测：匹配 / 未匹配；两组 CNR 中位数；AUC|
|---|---|---|
|[2](evidence/local-contrast/sample2.json)|64 / 9；4.54 / 2.49；0.821|64 / 7；4.70 / 3.53；0.891|
|[3](evidence/local-contrast/sample3.json)|17 / 10；3.82 / 3.66；0.588|17 / 9；4.09 / 3.55；0.745|
|[5](evidence/local-contrast/sample5.json)|7 / 5；5.26 / 3.09；1.000|7 / 3；5.31 / 5.03；0.571|

AUC 是本试件内每个匹配孔与每个未匹配孔两两比较，前者 CNR 较大的比例；相等计一半。6 组比较均有足够的对象且无零 MAD。没有一侧在三个试件上都达到预定 0.80。5 号参考侧的 1.000 只来自 7×5 对比较，不能推断一般检出率；同一孔参与多对比较。未作体积分层调整或显著性推断。
