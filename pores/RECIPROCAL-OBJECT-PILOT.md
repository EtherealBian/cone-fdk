# Reciprocal object transfer: separate pore discovery from boundary measurement

Keep the new profile mask as a detector. Test a single case-independent replacement of its matched complete object boundaries with measurements from the original census mask (no probability tuning, reference labels, coordinates, volume ranking or case-dependent rules). Motivation: the new detector gained eligible matches but the object-volume tail worsened on two transfer specimens. The reverse direction is a prespecified negative/mechanism control rather than a selectable alternative.

Use only the two already sealed masks per scan, 6-connectivity throughout. Partition their union into connected regions. In a region with **exactly one nonempty component from each input**, both strictly interior and >=64, and exact IoU >=1/2, replace the entire detector component by the other mask's component. Otherwise preserve the detector region unchanged, including empty, touching faces, split, merge and below-cutoff objects. This one-to-one eligibility lock implies no eligible component can be created, destroyed or merged relative to the detector; it does *not* guarantee the same reference matches. Tabulate all region sizes, unique component counts, reasons, matched pair IDs, IoU and actual replacements. For every label-free replacement check a second implementation using the native stable seed IDs and bounding boxes; regenerate both complete masks independently. Keep both original inputs as baselines. Seal masks and choice ledgers before any evaluation. Use only the familiar 96-layer development transfer area. No holdouts, no fitted weights and no truth-assisted selection.

After seal, re-measure all four arms with native 8/37, SciPy and the original matching. For the forward test (profile detector, census boundaries) require on each specimen versus its profile detector: zero lost matched references, no decline in either match fraction, at least five common matches and >=2 pp lower shared volume P95, all-match P95 no worse, Dice decline <=.002, exact independent decisions. Also show forward results against original census and complete results for the reverse control; no switching the primary direction after learning scores. An object transfer cannot by itself certify the formal gates. Failure closes this exact boundary lock; do not mix directions by specimen or case.
