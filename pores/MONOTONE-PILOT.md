# Can a monotone update improve the measurement, not just its gray residual?

Research transfer only, specimens 2/3/5, x=[360,616), y=[376,632), z=[256,352), already examined. No new training. Do not inspect formal or reserve slabs. Freeze all predicted masks before this study uses transfer labels. Reuse the public forward fit, phase endpoints, integer normalization, parent census and four-voxel margin verbatim. No chosen IDs, tuning runs, extra passes, or per-specimen choices.

**Fixed support**: only original voxels touching the other phase on at least one of their six faces may flip. This is a boundary correction; it cannot discover remote missing pores. Test two interventions separately. Mask the previous unconstrained synchronous predictions by this support (`band-sync`); this isolates restricting the domain. Optimize the same objective on the same support (`band-color`): visit the 125 residue classes `(z%5,y%5,x%5)` in lexicographic order, each voxel exactly once. Use current binary mask, the original census prior, integer single-flip gain, and current convolved field; flip only for strict improvement. A visited voxel still has its original value, but its neighbors need not. Distinct members of a class are at least five lattice units apart: radius-two forward footprints do not intersect and no face edge is shared. Their individual objective changes add exactly. Distinguish optimizer correctness from correspondence to the NIST labels.

**Mechanical checks before scoring**: independent CPU and native CUDA must agree on every decision on both arms; compare each color's changed count. No changes off the registered support. Using the full ROI, compute the original forward study's energy (raw residual sum of squares + S/12 per unequal unordered face + S/2 per change from census). Sum the exact integer single-flip gains for the colored sweep, publish each color and verify their energy change agrees with independent full-volume evaluation to 1e-10 per voxel; no class may increase energy. A deactivated class/tie stays unchanged. If any mechanical check fails do not score. Seal predictions, code/tool identities, edit counts and energies first.

**Measurement screen**: report unmodified census, unconstrained synchronous (previous public control), band-sync and band-color. Use the same one-to-one matching, ROI boundary, 64-voxel floor, 11 gates and SciPy/native 8/37 checks. For each new arm list gained/lost reference IDs, Dice, both coverages, all-matched and same-ID P95. Primary comparison: band-color vs unmodified census on every specimen (>=5 common, >=2 percentage-point reduction in same-ID P95, no decrease in either coverage, Dice loss <=.002). For a claim specifically that optimizer ordering helps measurement, require the same comparison vs band-sync too. Report both comparisons independently. Off-support change count must be zero; also count new false positives and new false negatives vs census, including deep (>4 voxels from opposite initial phase) flips. Zero deep errors by construction is not evidence of finding missing pores. Do not change the final gates. If this fails, retire this forward-kernel objective as a route to promotion on these data instead of tuning more passes, coloring or band thickness on transfer scores.
