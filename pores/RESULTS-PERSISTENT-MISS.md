# 三件始终漏配的孔，原始位置上发生了什么？

取[十二项实验目录](RESULTS-OBJECT-CATALOG.md)里**所有**从没被匹配的参考孔：2/3/5 各一个。回到同一份开发迁移区原始 CT 和分割，逐个核对七组预先指定预测的所有重叠分量，包括小于 64 体素和触及裁边的预测。三个孔都与预测有重叠，漏配的原因却不同。

|试件 / 参考 ID|参考体素|七组中各自最佳重叠的结果|原生 CT 中位数：孔内 / 一层面邻接材料|
|---|---:|---|---|
|[2 / 28](evidence/persistent-miss/sample2.json)|164|七组最佳分量都足够大、未触边，但 IoU 全小于 0.5；最高 90/212 = 0.425|47,978 / 49,365|
|[3 / 70](evidence/persistent-miss/sample3.json)|90|七组各只有一个重叠分量；都连到裁边、超过 113 万体素。交集有 44–81 体素，不能单独作为这个孔测量|38,900 / 40,353.5|
|[5 / 62](evidence/persistent-miss/sample5.json)|100|四组最佳分量不足 64；另外三组达到大小下限但 IoU 仍不足。最高 59/125 = 0.472，并非没有看到这个孔|47,038.5 / 49,361|

以上结果不能通过降低 64 体素计量下限、放松 IoU 或按参考坐标手工补孔来“修复”。只把 3 号巨大触边分量的体积调准，仍不能分出独立孔；只把 2 号预测做大，也不保证空间位置正确。七组都在使用相关的原图信息，不能将一致的错误视作七次独立测量。材料壳排除了其他参考孔，只用于事后描述；灰度值不做跨件标定比较。
