# Exact headroom of the seven-donor regional selector (reference-assisted diagnostic)

Register after the real medoid failed, before computing the regional bound. The twelve-study catalog allowed different donors for different matched IDs, dropped difficult matches and ignored all conflicts. What is attainable when **exactly one** of the same seven real donor restrictions must be copied for every connected region, no deleting matched objects, and all regions are scored together? This is a diagnostic only. Keep the exact same transfer crop, control panel, union, connectivity, size, clipping and match rule. No formal data, holdouts, fitting or alternative panel. Do not use an oracle mask for training, inference or promotion.

For each region and donor, enumerate every admitted pair (unclipped, >=64, IoU >=0.5) from original masks and the source segmentation. Verify that each reference that has any possible edge can reach only **one** union region across all donors. If this separability fails, report it and do not claim an exact optimum with this solver. Use original one-to-one assignment within each donor option, check against published matches (native IDs are seed-flat+1), retain all matches even if badly measured. Thus donor choices in different regions cannot change one another's assignments. Record candidate counts, unmatched IDs and regions containing several eligible references.

For each possible total matched count n, dynamic-program over regions. At these reference populations (max 49), the four largest absolute relative volume errors contain the exact linear-interpolation P95; compute the number required from population, not a hardcoded assumption. For the same count discard a partial worst-error vector only if another vector is componentwise no worse. Merging the same future donor multiset preserves that partial order. Keep a witness for each retained state. Use exact rational arithmetic for P95 / threshold decisions. Report maximum reference coverage and minimum attainable all-match P95 **over actual complete choices** with coverage >=90% (or undefined if impossible); also show values at each feasible count and all 7 donors unmixed. The other nine gates, including prediction coverage, are not part of the optimizer. Materialize a single descriptive witness (maximum coverage if required coverage is impossible), re-score its full binary mask with native 8/37, independent components and original matching; verify every claimed ID and volume. Do not train on or export the truth-assisted mask as a candidate. Publish per-region option ledgers, witness decisions and all scores, including failing cases. Test optimizer against exhaustive choice on small catalogs. A negative bound requires different predictions/region structure, not a better choice among these donors; a positive bound is not a selector.
