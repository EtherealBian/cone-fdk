# Five-plane decoder: does learned 3D evidence help at real pore boundaries?

A new architecture, not a correction head on a frozen CNN. Register before building the expanded features, fitting or scoring either arm. Target only development 2/3/5. This is a paired experiment, not the reserved-specimen manifest. The paper illustration is never supervision.

Use six fields per native z plane in this order: mapped raw center, 3×3×3 median, CUDA h30 NLM of median, Bernsen disk span, signed midgray minus mapped byte, and the clipped Bernsen prior. Use exactly the normalization/channels 0,5,6,7,8,9 and XY context of the sealed axial-raw frontend. Form features at z−2,−1,0,+1,+2 using **real** adjacent raw planes even at the ends of the supervised region. Obtain the four other planes' fields *before* any decisions. Pack six center channels followed by each of the four neighbor-minus-center vectors in ascending z order. In `slice` pass the same center plus four zero vectors; in `volume` pass the measured differences. One valid learned convolution over the complete 5×3×3 input (implemented as 30 planar channels), then the existing four remaining CNN stages with the same widths/dilations as census. Both models train every convolution from identical initialization, including the first layer; use the same fixed center Bernsen skip. No frozen logits, morphological postprocessing, per-scan heads or selection of best epoch. CUDA deploys the full learned operator without an external ML inference runtime.

Calibration: same 24 labelled center planes per scan z=[160,184), no new labels, verified overlapping fields against the original sealed calibration cache. Reuse census tile coordinates, transforms, seed 61429, 1536 updates, and BCE+0.1 tile relative mass, AdamW 0.002/0.0001 decay with cosine terminal LR 0.0001. All input channels undergo the same XY augmentation. For transfer only use centers [256,352); allow raw halo, never exterior labels. Require a scalar/matrix FP64 independent CPU forward vs native at every voxel in both arms, report every difference and maximum. Recompute the census hard masks from their frozen inputs or verify the previously public masks and use them as an external comparator. A third arm is not trained. Check genuine centered Z geometry, zero response to constant-Z through the differencing step, and equality to a direct 5×3×3 kernel on synthetic data.

Publish the six masks, both complete weight files, raw/cache identities and training traces **before** comparison with transfer labels. Export native object tables twice (depths 8 and 37), independent SciPy object checks and matched IDs. On each specimen independently, volume must retain both coverages and Dice within 0.002 and lower same-ID volume P95 by at least 2 percentage points on ≥5 common pores, against **both** slice and frozen census, with zero CPU/native decision differences; disclose all eleven component/voxel gates either way. This only admits a method to formal development; FINAL-GATE controls all reserve access.
