# 能从 CT 截面判断一个孔该不该改边界吗？

**这次不能可靠地判断。** 与曲率基线相比，选择器在 2 号把一个误差本来超过 15% 的孔拉回线内，没有把任何原本合格的孔推过线；但三件的体积误差 P95 都原地不动。研究筛选要求每件同孔 P95 至少降低两个百分点，没有一件达到。也没有增加或丢掉匹配。

保留所有原匹配，双侧覆盖率均超过 90%。上一轮拟合整体积调整比例时，5 号在 24 层校准区找不到一个合格完整孔。这一次用四连通的二维截面配对，可使用被切到的结构，但不估算其缺失的三维部分。326 个截面并非 326 个独立孔；同一试件、同一三维结构内都作了权重平衡。校准来自训练过父模型的区域，并非独立验证。

## 究竟差在哪里？

比较同一参考孔的原体积和完整灰度边界体积，事后才判哪个离参考更近。即使两个边界都在 15% 内，也可能有一个更近；正确选择次数不是过线孔数。

|---|---:|---:|---:|---:|---:|

三件共 80 个已匹配孔，**每个至少有一个端点在参考体积的 ±15% 内**。这是查过答案后的体积诊断，不是生产可用的选择器，也没有解决未匹配的孔、其他验收项或未见试件。5 号有 5 个已匹配孔的新边界比原来更准，实际只选中了其中 1 个。两端点的误差互补，但截面估计没识别出足够多的高误差孔。

冻结的共享岭回归用面积、周长以及内外层相对灰度预测每张截面的面积偏差。只在两张完整三维掩膜间选择，绝不按参考 ID 改孔。原生 CUDA 构建每个截面的暴露边和背景距离环，与独立 SciPy 实现逐字节比对；拟合、截面汇总和整孔选择在 CPU 执行。两次完整预测得到相同的 8 个文件；评分均重读源参考，运行 8/37 两种原生分块，并用 SciPy 核对逐孔记录。两次评分的 12 张 CSV 逐字节一致；四份 JSON 仅忽略原生计时后相同。
