# Prospective two-core split pilot (development only)

Lock this before reading the new development slab labels. Use E fit only on its original 24 calibration slices. New slab in specimens 2, 3 and 5: x=[360,616), y=[376,632), z=[552,680). None of the discovery slab [256,352), the formal ROI [400,528), or specimens 4/6 are validation data for this experiment. Do not replace sparsely populated slabs. Publish all baseline probability and split-mask digests before decoding any new evaluation annotations.

Use the unchanged bridge alert (six-connected p>=0.5 complete component, at least two p>=0.90 cores each >=32 voxels and >=5% of parent). Intervene only for exactly two eligible cores. Compute an integer minimum vertex cut between these two immutable cores on the parent's six-neighbor graph. Removing a non-core voxel costs 1 + floor(100*(p-0.5)); protected terminals and neighbor edges have greater capacity than the sum of ordinary costs. Use the residual source-reachable minimum cut with the lower scan-order core as source. Accept an edit only if it removes <=2% of the parent, produces exactly two six-connected daughters, each >=64 voxels, containing the two different cores. No recursion, no posthoc threshold choice, no modification elsewhere. Preserve the original mask as a separate arm.

Report every parent, its flag and outcome. A baseline merge event covers >=50% of each of >=2 distinct complete reference pores >=64 voxels. A verified rescue requires daughters matched one-to-one (IoU >=0.5) to two of these original references in the full-volume matching. Count edited non-events as unsupported splits, and specifically report formerly single matched pores now split without a second distinct reference. Missed/partial rescues and abstentions cannot be counted as successes. Report baseline/edited coverage, false predictions, per-pore volume P95 and all 11 gates on each new slab, and repeat both masks with the native 8/37-layer and CPU checks. Promote to a formal-ROI development test only if at least two verified rescues across at least two specimens, no unsupported edits, and no specimen loses a baseline matched reference, gains an unmatched prediction, or increases all-matched P95. No inference about accuracy on holdouts. A failed or undersupported split does not end work on the unchanged final goal.
