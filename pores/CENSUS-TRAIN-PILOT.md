# Coverage of calibration supervision: shuffled census versus sampling with replacement

Development only, 2/3/5. Previous adjacent-plane features raised transfer Dice on all three but did not consistently improve pore volume. Is some of the error caused by reusing calibration pixels while never supervising others? Keep raw inputs, model and optimization identical across new arms. Do not use any transfer or formal labels for fit/selection. This is a new paired study, not a comparison at equal compute against historical H or the 16-pixel axial run.

Partition the allowed calibration slab x=[360,616), y=[376,632), z=[160,184) into 1,536 nonoverlapping 32×32 output tiles per scan (8×8×24). At each of 1,536 updates draw one of these grid tiles and one off-grid transition-centered 32×32 tile per scan. In `census`, visit a seeded random permutation of all grid tiles once per scan. In `replacement`, draw the same number of grid tiles uniformly with replacement. Both use exactly the same off-grid centers: alternate all pore boundaries with the existing small-pore boundary pool, falling back to the former when empty. Both share all dihedral augmentations, initial weights and the entire schedule. Record actual distinct tiles and per-scan unique supervised voxel counts for both arms, including the common off-grid stream; do not infer coverage from update counts. No new annotations.

Use the ten-channel `axial` features and valid dilations 1/2/4/1, same fixed prior, threshold, BCE plus 0.1 relative count loss (denominator 16+positive tile count), seed 61429, deterministic AdamW .002 to .0001 cosine, 1536 updates (no early stopping). Freeze both weights and all six raw-derived masks for the previously studied 96-plane transfer interval z=[256,352) before scoring these predictions. Confirm native CUDA vs an independent CPU convolution on every decision, native 8/37 slab invariance, source and artifact hashes. Report both-sided object coverage, all 11 thresholds and paired P95 with reference IDs. Advance the census method only on all three: >=5 common matched pores; >=2 percentage points better common-pore volume P95, neither coverage fraction lower, Dice no more than .002 lower, zero replay decision differences. No winner selected post hoc. No formal re-evaluation, reserve access or final freeze unless prior gates are met.
