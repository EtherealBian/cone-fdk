## 怎么得出这些数

1. 以解析管壁、夹具和三个随管件移动的标记模拟五次探测器采集，各自使用固定且不同的泊松噪声种子。跨缝减薄与无改变对照共用一份基准；五次采集不等于五件独立工件。
2. 测量只读取投影、通常的标定和预设阈值。通过工装定位与三个体标记检查后，在材料坐标系中比较 41 × 360 条径向剖面。两次扫描各取 0.018、0.020、0.022 mm⁻¹ 三个边缘阈值，整件共九组配对；减薄 ≥ 0.30 mm 才计入足迹。
3. 评分器独立计算设计径向减薄，把检测区域与设计区域按总 IoU 最大作一对一配对，不拟合峰值、不平移图像。每组必须完整覆盖，区域数与跨缝状态都正确，IoU ≥ 0.85，面积误差 ≤ 15%，标称峰值绝对误差 ≤ 0.065 mm，全部阈值组合 ≤ 0.12 mm。
4. 独立 CPU 洪泛核对 27 张标签图（398,520 个配对单元）；每次标称比较另与原生 CUDA 减薄图逐格核对。三个批条目首次计算与各自单件结果相同；恢复时三条全部复用。错位、额外区域、盲区、错误峰值和错误跨缝标记在测试中必须被拒绝。

## 复跑

使用 Git 检出源码（保留 `.gitattributes` 指定的行尾）并在 Windows 上构建后，在仓库根目录运行（输出目录必须新建，`--keep` 可省略）：

```powershell
python scripts/replay_specimens.py --expected reports/specimen-qualification.json --evidence build/my-specimen-replay.json --keep build/my-specimen-run
```

这会重新生成五套带噪投影，计算三组有见证的测量，生成批次和离线 HTML。程序将新的整份资格 JSON 与参考逐字节比较，并核对 HTML 摘要。也可以向 `Run-Acceptance.ps1` 加 `-SpecimenCampaign`，连同原模拟、核桃投影和超显存回归运行（不要加 `-CoreOnly`）。逐字节复现的预期适用于已记录的同工具链环境。

**适用边界：** 两种几何共用夹具与材料模型，噪声来自少量固定种子；27 张图不是 27 个试件，也不是精度的置信区间。尚无实物管件及可溯源尺寸真值、真实散射或多能谱校准。这些数不能作为 5060 对实物的公差保证。
