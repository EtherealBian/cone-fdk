# 车间离线机怎样恢复一批长管件的复核？

一次查看多件材料的连通结果时，最容易犯的错是拿上一件的结论填补当前缺失的数据。本入口对每条作业单独校验、提交、恢复；一条定位拒测不会生成拓扑，缺批件也不妨碍其他件完成。处理单位是已见证的边缘作业，输入壁厚由上游 CUDA 产生；本工具在 CPU 上复核，不需要重新采集或重建。

## 从一个可运行的例子开始

在仓库根目录，将公开壁图解压一次，然后使用同一个配方和输出目录运行两次：

```powershell
Expand-Archive reports/edge-review-example.zip build/stripe-edge-example
python scripts/stripe_batch.py fixtures/stripe-demo-plan.json build/my-striped-batch
python scripts/stripe_batch.py fixtures/stripe-demo-plan.json build/my-striped-batch --resume
```

[单件配方](../fixtures/stripe-demo-plan.json)选择减薄峰值附近的两个点；示例的九组阈值都有实测连通。第一次计算，第二次重新校验 3,084,840 B 壁图及包络，不重复做连通标记。已解压过同名示例时跳过第一步。查看 `manifest.json` 中的 `entries`；按 `result_file` 打开普通 JSON，可查每组阈值的区域数、最大超限片格数和两点的状态。

自己的配方可以混排 1–1,024 个条目。每条指定唯一 `id`、源目录以及从可信交付清单取得的 `manifest_sha256`。`edge` 条目必须自定两个材料坐标 `[轴向行, 方位列]` 和 `band_rows`；`witness-refusal` 只填写来源，不接受锚点。相对路径按配方目录解释。[完整的十条资格配方](../fixtures/stripe-campaign-plan.json)指向资格运行保留的原始作业，普通源码检出不自带这些中间文件。

## 中断后哪些工作会重做？

- 已提交的作业：检查结果的内容摘要，再以 **最多 1 MiB/次**读当前作业消耗的壁图和包络；几何及源清单另作校验。全部字节与原件一致才复用结果。不是仅凭文件名、长度或修改时间命中缓存。拒测条目恢复时同样复核原始拒测原因。
- 正在计算、尚未提交的作业：重新从该作业第一带开始。本版检查点在**件与件之间**，还不能从一件的大网格中间接着算。开始复核后先撤掉旧的完工索引，仅当所有条目已处置时发布本轮索引。
- 源损坏或缺失：该条标为 `input_error`，不输出上一次的坐标判读或结果链接，其他件继续。恢复原字节后可再续跑。检查点自身损坏、写者争用、配方/算法版本变化均不静默复用。检查点绑定 Python/NumPy/SciPy 版本及执行脚本摘要；旧详细标签批检的日志也不能拿来恢复本摘要。
- 完整/不完整覆盖、上游拒测分别保留。命令退出码 **0** 仅完整覆盖，**2** 存在有效但不完整的结果或上游拒测，**1** 输入或任务错误；都不是实物放行依据。此本地方案假定信任配方、软件和写入日志的机器。内容摘要不是数字签名，也不是断电耐久性认证。

## 实机资格结果

在原仓库的 **10 条作业**（并非 10 个独立实物试件）上，7 条完整、1 条覆盖不全、2 条上游拒测。67 张配对图、988,920 个配对单元与独立的已验收模拟作业、整图记录和锚点判读一致。

| 检查 | 结果 |
|---|---|
| 冷启动 | 首次生成 10 条结果，其中 2 条仅记录拒测原因 |
| 正常续跑 | 10 条复用，0 条重算；重新读取 23,734,080 B 壁图/包络 |
| 第五条开始前强制退出子进程 | 此时没有完工索引；重启复用前 4 条、完成剩余 6 条，最终索引与冷启动逐字节相同 |
| 跨试件判读 | 跨缝外平面 9/9 连通；其原样复扫的锚点 9/9 低于门槛；双缺陷的两个锚点 9/9 分开。两个临界窄桥各 3 连/6 断；不完整对照仍有 3 组需要盲区才能连通。各组设置不是独立样本。 |

## 在干净源码检出中从头复算

按仓库说明构建两次原生程序，安装锁定的 Windows Python 依赖；不必先下载或手动拼接上面的十个工作目录。下面一条命令从模拟射线重新生成见证扫描、两种独立管件和窄桥，使用外部冻结清单逐项比对，最后重放强制中断。默认在临时目录运行，只留下新证据文件；要保留投影、壁图、原生行程和 SQLite 日志，可追加 `--keep build/my-fresh-stripe-work`（必须是新路径）。

```powershell
python scripts/replay_stripe_mixed.py reports fixtures/stripe-campaign-plan.json build/my-detector-to-stripe.json
```

这条命令不重复测试真实核桃的 720 投影重建，也不代替大网格的独立压力测试。两项的验收见[分带摘要报告](STRIPED-REVIEW.md)。
